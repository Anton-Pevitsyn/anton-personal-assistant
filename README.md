1# Личный ассистент Антона

Первая версия: текстовое общение, доступ только владельцу в личном чате,
контекст последних 20 сообщений (10 пар вопрос–ответ), очистка истории /new.
Корпоративные материалы, файлы ChatGPT, интернет, голос и напоминания не подключены.
История хранится в SQLite на постоянном диске Railway. Это не бессрочная память.

## Размещение

1. Распакуйте архив. Создайте приватный репозиторий GitHub и загрузите содержимое
   этой папки в корень репозитория, включая Dockerfile и bot.py. Ключи не загружайте.
2. Railway: New Project → Deploy from GitHub repo → выберите репозиторий.
3. Сервис → Variables: добавьте TELEGRAM_BOT_TOKEN (токен BotFather),
   OPENAI_API_KEY (ключ OpenAI), OWNER_TELEGRAM_ID (ваш числовой ID),
   OPENAI_MODEL=gpt-4.1-mini, DB_PATH=/data/bot.sqlite3.
   Все три первых значения вводите непосредственно в Railway.
4. Подключите к сервису Volume с Mount Path /data. Без него история теряется
   после пересоздания контейнера. Держите одну реплику сервиса.
5. Выполните Deploy/Redeploy. Публичный домен не требуется: используется polling.
   Отключите Serverless/App Sleeping для постоянной работы, если этот режим включён.
6. В логах должно появиться: Bot started; owner-only access enabled.
7. Откройте @AntonGenLeeAssistantBot, нажмите Start и отправьте сообщение.

## Как получить Telegram ID без стороннего бота

Напишите любое сообщение своему боту до запуска приложения.
На своём компьютере откройте Terminal, выполните `python3 owner_id.py`.
Введите токен BotFather: ввод скрыт. Скрипт покажет ID отправителей личных сообщений.
Выберите запись, относящуюся к вашему сообщению. Не выбирайте первый ID автоматически.
Если записей нет, напишите боту снова и повторите. Скрипт не работает параллельно
с запущенным ботом: сначала остановите сервис Railway.

## Проверка

Попросите запомнить тестовое слово, затем спросите его в следующем сообщении.
Перезапустите сервис и повторите вопрос: история должна сохраниться.
После /new старое слово не должно быть доступно из истории.
С другого Telegram-аккаунта бот не должен отвечать; в группе тоже.

## Ограничения

На момент подготовки проверены локальные сценарии с имитацией внешних API.
Реальное подключение к Telegram/OpenAI и развёртывание требуют ваших настроек.
Расходы Railway и OpenAI контролируйте в соответствующих кабинетах.
Модель можно заменить через OPENAI_MODEL на доступную вашему проекту.
Приложение не логирует переписку и секреты. Текст отправляется в OpenAI для ответа.
/new очищает локальную историю, а не сообщения Telegram или журналы провайдеров.
При сбое между обработкой сообщения и сохранением offset возможен повтор ответа.
